This module allows importing Ticket Log data from XLS/XLSX files to create purchase orders.

Features:

- Import fuel data from Excel files
- Import toll data from Excel files
- Vehicle validation by license plate
- Analytic account validation by work name
- Driver (partner) validation
- Product validation by fuel type
- Duplicate detection via hash
- Odometer record creation
- Driver update on vehicle

Usage
=====

Usage:

1. Go to: Purchases > Ticket Log > Import Fuel (or Import Toll)
2. Select vendor/supplier
3. Select XLS/XLSX file
4. Click "Preview" to validate data
5. Click "Import" to create purchase order

Configuration:

- Vehicles must exist in fleet.vehicle with license_plate
- Analytic accounts must exist in account.analytic.account
- Drivers (partners) must exist in res.partner
- Products must exist in product.product

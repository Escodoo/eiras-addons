Usage:

1. Go to: Purchases > Ticket Log > Import Fuel (or Import Toll)
2. Select vendor/supplier
3. Select XLS/XLSX file
4. Click "Preview" to validate data
5. Click "Import" to create purchase order

Configuration:

- Vehicles must exist in fleet.vehicle with license_plate
- Analytic accounts must exist in account.analytic.account
- Drivers (partners) must exist in res.partner
- Products must exist in product.product

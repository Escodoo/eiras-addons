This module extends *Fuel Stock Consume* with a consumption wizard for tanker truck refueling operations.

It allows operators to partially consume fuel from a supply location (tanker truck),
recording vehicle, driver, and odometer data, while automatically validating
stock pickings and generating backorders for the remaining quantity.

Key features:

- Partial fuel consumption from tanker trucks
- Automatic backorder generation for remaining fuel
- Vehicle, driver, and odometer tracking per consumption
- FIFO consumption across multiple assigned pickings
